# Чужая SSH-машина

[English](../en/providers/machine.md) · **Русский**

Код: `src/resalloc/providers/machine.py`.

Это хост, до которого хаб сам открывает SSH: лабораторный сервер, уже арендованная VM, второй компьютер. Ноутбук сюда не входит. До ноутбука хаб через NAT не достучится, поэтому ноутбук сам стучится наружу (`resalloc laptop agent`).

| Настройка | Смысл |
| --- | --- |
| `host`, `user`, `port` | куда подключаться. Имя хоста без пробелов и без shell-символов |
| `identity` | приватный ключ на хабе. Без него берётся ключ ssh по умолчанию |
| `workdir` | каталог на машине, по умолчанию `/var/tmp/resalloc/<job>` |
| `python` | интерпретатор, по умолчанию `python3` |
| `gpu` | подпись для журнала. Хаб видеокарту не выбирает: она уже стоит в машине |

Цена для политики — ноль. `stop` убивает процесс из `worker.pid` и не выключает машину. Пропал SSH — тот же обрыв, что и пропавший под: задача уходит на следующий провайдер. Ненулевой код скрипта — `worker_failed`, цепочка останавливается.

Прямая заливка датасета идёт с ноутбука на этот же SSH. Ключ ноутбука тоже должен быть в `authorized_keys`, если байты не кладутся на хаб.
