# Ноутбук

[English](../en/providers/laptop.md) · **Русский**

Код: `src/resalloc/providers/laptop.py`, `src/resalloc/laptop_agent.py`.

Бесплатный провайдер. Цена в политике — ноль. Хаб в домашнюю сеть не подключается: на ноутбуке работает `resalloc laptop agent` и сам шлёт пульс.

| Настройка | Смысл |
| --- | --- |
| `cpus` | сколько ядер занять, для заявки |
| `ram_gb` | сколько памяти занять, для заявки |

Если при сдаче выбран ноутбук, а пульса нет, сдача сразу кончается ошибкой.

`Dataset(..., keep="laptop")` не копирует байты. Скрипт крутится рядом с ними.

Каждый `worker.save` при агенте по SSH вызывает `resalloc laptop push`, так что чекпоинт уходит на хаб сразу, а не в конце процесса. Пропал пульс дольше `laptop_heartbeat_timeout` — для хаба это обрыв, как пропавший под. Дальше идёт `failover`, если он задан, с последнего чекпоинта, который успел уехать.
