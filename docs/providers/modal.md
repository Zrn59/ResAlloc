# Modal

[English](../en/providers/modal.md) · **Русский**

Код: `src/resalloc/providers/modal_backend.py`, заливка датасета в `src/resalloc/data_stores.py`.

Долгий запуск — `modal.Sandbox`, не декоратор функции. Код задачи лежит на томе `resalloc-<job>`. Отдельный постоянный том задаётся `volume`: он монтируется в `/data` и переживает задачу. Туда и идёт `Dataset(..., keep="modal")`. Это бесплатное хранилище, GPU в этот момент не нужен, байты на диск хаба не садятся.

| Настройка | Куда попадает |
| --- | --- |
| `gpu` | `Sandbox.create(gpu=...)` |
| `image` | `Image.from_registry`, иначе Debian + `requirements.txt` |
| `cpu`, `memory_mb` | `cpu`, `memory` |
| `timeout_hours` | `timeout` в секундах |
| `volume` | постоянный том на `/data` |
| `region`, `cloud` | те же аргументы Sandbox, если заданы |
| `env` | окружение вместе с `RESALLOC_JOB_DIR` |

Деньги: `Workspace.billing.summary`. Потолок сравнивается с `metered_cost` (счётчик до вычета кредитов). `billed_cost` остаётся нулём, пока бесплатные $30 покрывают расход, и по нему лимит сработал бы слишком поздно. Если почасовой отчёт ещё не закрыт, скорость считается от первого показания счётчика в этой сессии, а не от прошлого минутного опроса: счётчик Modal обновляется пачками. Поля «осталось $30» нет. Потолок — `modal_max_spend_usd`.

Прямая заливка с ноутбука требует пакет `modal` и токен на ноутбуке. Хабу токен нужен, чтобы открыть и закрыть Sandbox. Сигнал остановки — файл на томе кода и `terminate`.
