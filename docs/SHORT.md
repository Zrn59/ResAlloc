# resalloc, коротко

[English](en/SHORT.md) · **Русский**

Поставить: `resalloc help`. Хаб здесь — `resalloc up`. Ноутбук сдаёт задачи, а хостинг является узлом — `resalloc up --ssh-host ИМЯ`, где `ИМЯ` уже есть в `~/.ssh/config`.

Ноутбук сдаёт задачу. Хаб следит за деньгами и квотой и переносит один и тот же `train.py` между Runpod, Vast.ai, Modal, Kaggle, обычной SSH-машиной и ноутбуком. Чекпоинты и журнал всегда на хабе. Сам датасет туда класть не обязательно. Сколько задач держать сразу — `hub.toml` на хабе (`max_running` и лимит на каждый провайдер). Скрипт, который сам упал, дальше по списку не переносится: это `worker_failed`, его продолжают через `resalloc resume` после правки.

Три дороги для данных:

- `hub` — копия на диске хаба. Для маленьких наборов.
- `direct` — с ноутбука сразу в хранилище провайдера, без диска VM. Modal-том (бесплатный терабайт) и Kaggle-датасет заливаются до запуска GPU.
- `stream` — то же самое кусками по 8 МиБ, без сборки всего файла в память. У Runpod скрипт может читать уже доехавшие файлы через `worker.iter_ready`.

```python
from resalloc import Dataset, Job, Modal, ResAlloc

ResAlloc.submit(Job(
    script="train.py",
    start=Modal(gpu="A10G", volume="datasets"),
    datasets=[Dataset("./huge", route="direct", keep="modal", store="datasets")],
))
```

Пороги `Limits` просят сохраниться заранее и гасят запуск, если денег или часов осталось мало. Общие потолки, чтобы не повторять их в каждой задаче, лежат в `[limits]` файла `config.toml`. `resalloc config` показывает текущие настройки и имена секретов. `confirm=True` не держит платный GPU, пока ноутбук закрыт. Когда задача начинает ждать подтверждения, хаб один раз шлёт `notify_url` или запускает `notify_command` из `hub.toml`. `resalloc attach JOB` подтверждает следующий шаг из терминала. `Vast(gpu="RTX 4090")` снимает дешёвый оффер само. `Machine(host="lab.example")` считает на уже доступном по SSH хосте и при остановке его не выключает.

Каталог задачи называется по скрипту и местному времени: `jobs/train-2026-10-31-18-11-a3f9`. Внутри `checkpoints` — промежуточное, `logs` — вывод. Своё имя: `name="city"`.

Ключи API лежат на хабе в `secrets.env` (по умолчанию `~/resalloc/secrets.env`). Прямая заливка на Modal или Kaggle использует ключи ноутбука, потому что байты идут мимо хаба.
