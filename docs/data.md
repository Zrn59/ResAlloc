# Данные: хаб, напрямую, поток

[English](en/data.md) · **Русский**

Код: `src/resalloc/data.py`, `src/resalloc/data_stores.py`, сдача в `src/resalloc/client.py`.

Хаб — диспетчер и склад чекпоинтов. Его диск общий с системой, поэтому датасет на сотни гибибайт туда не копируется. Бесплатный том Modal и датасет Kaggle живут у провайдера.

| route | keep | Что происходит |
| --- | --- | --- |
| `hub` | `hub` | хеш, кэш на VM, провайдер получает копию с хаба |
| `direct` | `modal` | ноутбук заливает файлы в том `store` до старта GPU |
| `direct` | `kaggle` | `kaggle datasets` читает исходную папку, второй копии нет |
| `direct` | `runpod` / `vast` / `machine` | хост поднимается, скрипт ждёт `COMPLETE`, байты идут с ноутбука по SSH |
| `stream` | `modal` / `kaggle` | те же хранилища, но кусками по 8 МиБ и с маркером на каждый файл |
| `stream` | `runpod` | под уже считает, `worker.iter_ready` видит файлы по мере прибытия |
| любой | `laptop` | байты остаются на ноутбуке, в заявке только путь |

`store` — имя тома Modal, слаг датасета Kaggle. Если пусто, для Modal берётся `Modal.volume` или `resalloc-data`.

Маркеры потока: рядом с файлом лежит `имя.done`, в конце каталога — `COMPLETE`. Пик дополнительной памяти — один кусок, не весь датасет.

Чекпоинт и логи после остановки хаб забирает к себе. Это отдельные маленькие файлы, не датасет. При переносе на другой провайдер большой датасет сам не едет: у Modal он остаётся на томе, для Runpod его нужно снова отдать с ноутбука, если ноутбук включён.

Прямая заливка на Modal и Kaggle требует ключей на ноутбуке. Ключи на хабе нужны, чтобы запускать и останавливать машины.
